# 🛒 E-Commerce Site

A full-stack **E-Commerce web application** developed using **Django, Python, HTML, CSS, and JavaScript**. The application provides a smooth online shopping experience with user authentication, product browsing, shopping cart, order management, and checkout functionality.

## ✨ Features

* 🔐 User Registration & Login
* 🛍️ Product Listing & Details
* 🛒 Shopping Cart
* 📦 Order Management
* 💳 Checkout & Payment
* 👤 User Account Management
* 📱 Responsive Design
* ⚙️ Django Backend & Database Integration

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Django
* **Database:** SQLite / PostgreSQL
* **Tools:** VS Code, Git, GitHub

## 🚀 Project Purpose

The project was developed to gain practical experience in **full-stack web development**, including frontend design, Django backend development, database management, user authentication, and e-commerce functionality.
